# 读图与 bug 理解卡

## 读图

对每张图记录：

- 图的来源：正文、重现步骤、评论或附件。
- 页面或场景。
- 红框、箭头和标注指出的内容。
- 当前实际结果。
- 用户期望结果。
- 图中能看到的账号状态、数据和操作提示。

图与正文冲突时把冲突写出来，不自行选择更省事的一方。看不清或图片打不开时停止判断，并说明缺哪张图。

## bug 理解卡

```text
工作项：PROJ-10
标题：<原题>
场景：<页面 / 接口 / 环境>
前提：<角色、权限、数据、版本>
操作：<可复现步骤>
实际：<截图或日志显示的实际结果>
期望：<需求或截图显示的期望结果>
证据：[图1] ... [图2] ...
分类：A / B / C / D
判断依据：<代码、需求、历史提交或需要确认的点>
```
